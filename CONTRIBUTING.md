# Cómo colaborar

Gracias por ayudar con **Nova PX Event Launcher**.

1. Haz un fork y crea una rama (`git checkout -b mi-cambio`).
2. `npm install`, luego `npm start` para probar y `npm test` antes de enviar.
3. Mantén el estilo del código existente y escribe la interfaz en español.
4. Abre un Pull Request explicando qué cambia y cómo lo probaste.

**Seguridad:** nunca subas tokens, contraseñas de eventos ni mods sin cifrar. Si encuentras una vulnerabilidad, escribe por [Discord](https://discord.gg/VAfuFEQtjv) en privado a un administrador en vez de abrir un issue público.
