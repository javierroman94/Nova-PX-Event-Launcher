# Lista de pruebas en Windows

Marca cada punto al probar una versión nueva. Si algo falla, anota qué pasó (captura o mensaje de error) y la versión.

## Lanzar el juego
- [ ] Perfil Vanilla abre Minecraft
- [ ] Perfil Fabric abre Minecraft
- [ ] Perfil Forge abre Minecraft
- [ ] Perfil NeoForge abre Minecraft
- [ ] Perfil Nova instala Nova Client (menú con Shift derecho, zoom con C)

## Modpacks
- [ ] Instalar un modpack de Feed The Beast
- [ ] Importar un `.zip` de CurseForge
- [ ] Búsqueda de CurseForge (hoy devuelve 403)

## Eventos
- [ ] Participantes con cabeza 3D fija (sin movimiento)
- [ ] Naciones separadas por grupo, con títulos
- [ ] Ganadores con cabeza 3D

## Mascota PX
- [ ] Aparece, saluda y mira al cursor
- [ ] Se duerme tras ~90 s sin actividad y despierta al clic
- [ ] Comenta: abrir juego, cerrar juego, modpack listo, cambio de tema
- [ ] Se puede apagar en Ajustes

## PX AI (opcional)
- [ ] Activar la casilla de PX AI en Ajustes
- [ ] Chatear y recibir respuesta
- [ ] "Revisar mi último error" tras un cierre inesperado
- [ ] "Olvidar todo" borra la memoria
- [ ] Al pasar el límite diario avisa sin romperse

## Cuentas y otros
- [ ] Iniciar sesión con Microsoft y con nick local
- [ ] Cambiar entre varias cuentas
- [ ] Actualización automática desde la versión anterior
